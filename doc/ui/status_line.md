# Status line 

A status line on the very bottom of the screen.

# Status line items, left

- Status - currently "(green dot) Ready", but can be updated by different processes

# Status line items, right, separated by |

- Pamatcad x.x.x OCCT x.x.x - versions
- x.xx GB ram - total memory footprint
- (console icon) Debug console - toggled [Debug console](logs_and_console.md)
