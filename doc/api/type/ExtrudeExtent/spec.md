# Name

Extrusion end condition

# Short Description

Choose where one side of an extrusion stops.

# Description

Each end condition is measured from the extrusion's start plane in that side's direction.

# Variants

## `length` — Distance

Enter the distance to extrude. You can enter a number or a length formula.

## `throughAll` — Through all

Extend through the forward reach of the target bodies in this direction.

## `toObject` — To object

Select a limiting body, then choose where the advancing end cap stops.
