# Name

Extrusion start

# Short Description

Choose where the extrusion begins.

# Description

The start plane stays parallel to the profile.

# Variants

## `profilePlane` — Profile plane

Begin on the plane containing the selected profiles.

## `offset` — Offset

Enter a distance from the profile plane. A negative distance places the start on the opposite side.

## `object` — From a face

Select a face. The start plane passes through its nearest point measured along the profile normal. If the face crosses the profile plane, the extrusion begins on the profile plane.
