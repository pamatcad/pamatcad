# Bundled sketch font

`Roboto.ttf` is the variable Roboto font (`Roboto[wdth,wght].ttf`) from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/roboto). Its SIL Open Font License is retained in `OFL.txt`.

SHA-256: `d7598e12c5dbef095ff8272cfc55da0250bd07fbdecbac8a530b9b277872a134`.

The committed bytes are used identically by native and WASM builds. No font download or system font lookup is needed at runtime.
